# unityroom への投稿

## 手順

1. `bash tools/check.sh` が ALL OK
2. `bash tools/export_web.sh` で書き出す(`tests passed` が出ること)
3. `bash tools/unityroom/make_thumbnails.sh` でサムネイルとスクリーンショットを作る(3分ほど。ウィンドウが開く)。
   エンコードだけやり直すときは `--reuse`
4. unityroom の「ゲームを登録」で下の文面を貼り、ファイルを上げる

| 上げるもの | ファイル |
|---|---|
| ゲーム本体 | `build/web/index.pck`(unityroom へ上げるのは pck だけ。エンジンは unityroom 側が持つ) |
| サムネイル | `build/unityroom/icon_512.gif`(512x512・512KB以下) |
| スクリーンショット | `build/unityroom/screen_*.png` |
| 紹介文や告知に貼る動き | `build/unityroom/play_640.gif` |

- Godot のバージョンは **4.6.2** を選ぶ(書き出しに使った版と合わせる。違うと起動しない)
- 表示サイズは **1280×720**(16:9)
- アップロードは、編集ページを開き直してから行う。アップロード先の署名付きURLはページを開いてから数時間で切れ、
  切れるとコンソールに「CORS policy」「upload failed: pck」としか出ない(`砂時計pvp` の build-and-announce Skill)

## 投稿文

**タイトル**

コンビニウォーズ

**ゲームID(URLになる。後から変えない)**

conveni-wars

**想定プレイ時間**

1試合5分

**紹介文**

```
向かいのコンビニと、同じ客を取り合え!

通りをはさんで向かい合う2軒のコンビニ。朝・昼・夕方・夜と時間帯が進むたびに、
会社員・学生・主婦・夜勤…と、やって来る客と欲しがる物が入れ替わります。

「次に来る客」の予報を読んで先に発注し、3×3の棚に並べた店に客が流れ込みます。
読みが当たれば、自分の棚から「+¥」が次々に飛び出す!

・値段を下げれば客は来るけど、儲けが減る
・仕入れすぎれば廃棄、少なすぎれば客を相手の店へ逃がす
・突然押し寄せる「工事現場の昼休み」「夕立」などのまとめ買いを読めるか
・晴れ・雨・猛暑・寒い日。天気で売れる物が変わる

4人の店長から1人を選び、試合中に1回だけ使えるスキルで勝負をひっくり返そう。
1日(5分)の利益が多いほうが勝ち。CPUの強さは3段階。
全店長で「つよい」に勝つのが目標です。
```

**操作方法**

```
マウス(またはタッチ)だけで遊べます。

・下の品ぞろえの商品を、棚のマスへドラッグして並べる(タップで選んでマスをタップでもOK)
・棚のマスの「発注」ボタン … 5秒後に30個届く
・棚の商品をタップ … 値段(安売り/定価/強気)・自動発注・棚から外す
・右下の店長のボタン … アクティブスキル(1試合に1回)
・Esc または右上のボタン … 一時停止

遊び方はタイトルの「遊び方」から、試合中のヒントでも案内します。
```

**タグ**

対戦 / 経営 / シミュレーション / CPU戦 / リアルタイム / コンビニ / 5分
