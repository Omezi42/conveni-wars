# 7章 店長キャラ

試合前に店長を1人選ぶ。CPUも店長を1人選ぶ(8章)。同じ店長どうしの対戦も可。

- **パッシブスキル**:試合中ずっと効く
- **アクティブスキル**:試合中にいつでも1回だけ使える。開店準備中(1章)は使えない

## 7.1 初期の店長

| 店長 | パッシブ | アクティブ |
|---|---|---|
| ベテラン | 発注の原価が −10% | **大量発注**:棚に割り当てた商品すべてに、50個ずつ無料で即座に届く |
| 元アイドル | 学生・若者から見た自店の魅力度が ×1.2 | **握手会**:10秒間、来店する客はすべて自店を選ぶ(両店とも魅力度0なら帰る) |
| 節約上手 | 値下げ(変化率がマイナス)の値段補正の効きが1.5倍 | **タイムセール**:15秒間、自店の全商品の値段補正を「大安売り」として計算する。売値は変わらない |
| データ分析 | 客層予報に、次の時間帯に加えてその次の時間帯も出る | **値札ロック**:20秒間、相手は値段を変えられない |

- 「値段補正の効きが1.5倍」は、5.2節の式の `変化率 × 2.5` を `変化率 × 3.75` にすること
- 店長はデータ(`.tres`)で持つ。スキルの効果の種類はコードで実装し、数値はデータで持つ
