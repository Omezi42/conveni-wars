# 7章 店長キャラ

試合前に店長を1人選ぶ。CPUも店長を1人選ぶ(8章)。同じ店長どうしの対戦も可。

- **パッシブスキル**:試合中ずっと効く
- **アクティブスキル**:試合中にいつでも1回だけ使える

## 7.1 初期の店長

| 店長 | パッシブ | アクティブ |
|---|---|---|
| ベテラン | 発注の原価が −2% | **大量発注**:棚に割り当てた商品すべてに、10個ずつ無料で即座に届く |
| 元アイドル | 学生・若者から見た自店の魅力度が ×1.15 | **握手会**:10秒間、来店する客は、自店の魅力度が0でなければ自店を選ぶ。自店が0の客は通常どおり選ぶ(両店とも0なら帰る)。両店が同時に発動しているときも通常どおり選ぶ |
| 節約上手 | 安売りの値段補正の効きが2倍 | **タイムセール**:20秒間、自店の全商品の値段補正を「安売り」として計算する。売値は変わらない |
| データ分析 | 客層予報に、次の時間帯に加えてその次の時間帯も出る。突発イベントの予告が5秒早く出る。発注が届くまでの時間が2秒(通常5秒) | **値札ロック**:45秒間、相手は値段を変えられない。自店の全商品が「強気」の売値で売れる。値段補正は自店の値段の段階のまま計算する |

| 店長 | パッシブ(短く) | アクティブ(短く) |
|---|---|---|
| ベテラン | 仕入れが少し安い | 並べた商品が全部、10個ずつ無料で届く |
| 元アイドル | 学生と若者に人気 | 10秒間、客をほぼ独り占め |
| 節約上手 | 安売りがよく効く | 20秒間、値下げせずに安売りの客寄せ |
| データ分析 | 予報が2つ先まで見え、発注が早く届く | 45秒間、相手の値段を固めて自店は高値で売る |

- 「安売りの値段補正の効きが2倍」は、5.2節の式の差(自店の段階の率 − 比べる率)が負のとき、`× 2.5` を `× 5.0` にすること
- 握手会で自店の魅力度が0の客を奪えないのは、並べていない商品の客まで奪えると棚を作る意味が薄れるため
- 値札ロックの売値はタイムセールの逆(呼び込みは変わらず、売値だけ上がる)。値段の読み合いをしないCPUでも効くようにするため
- スキルの数値は、1.5節の調整の目標(店長ごとの勝率40〜60%)に合うように決める。利益で競うため、原価や無料の商品のようにそのまま利益になる効果は小さな数でも勝率に強く効く
- 店長選択のカードには、スキルを計算の用語を使わない短い言葉で出す(下の表)。上の表の正確な効果は、カードにカーソルを乗せるか長押ししたときに出す
- 店長はデータ(`.tres`)で持つ。スキルの効果の種類はコードで実装し、数値はデータで持つ
