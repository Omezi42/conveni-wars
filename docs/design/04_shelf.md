# 4章 棚とボーナス

## 4.1 棚

- 3×3の9マス。1マスに1種類の商品を割り当てる
- マスは在庫を持たない。在庫は商品ごとに店で1つの数として持つ(6章)
- 割り当てた商品の在庫が0になると、そのマスは「空」になり、魅力度に数えない
- マスへの割り当て方は6章

## 4.2 ボーナス

棚の倍率は、次をすべて掛け合わせたもの。

| ボーナス | 条件 | 倍率 |
|---|---|---|
| 目玉 | 中央のマスに置いた商品 | ×1.5 |
| コーナー | 縦1列の3マスが同じカテゴリ(3マスとも在庫あり) | その3マスの商品が ×1.3 |
| セット | 上下左右に隣り合う2マスが、下のセット表の組み合わせ(両方在庫あり) | その2マスの商品が ×1.3 |

- 1つのマスに付くセットのボーナスは1回だけ(隣に複数のセットが成立しても ×1.3)
- 画面上では、成立しているボーナスをマスの枠と名前で示す(9章)

## 4.3 セット

| セット名 | 組み合わせ(カテゴリ) |
|---|---|
| おにぎりセット | おにぎり + 飲料 |
| 朝ごはんセット | パン + コーヒー |
| お昼セット | 弁当 + 飲料 |
| おやつセット | 菓子 + 飲料 |
| 晩酌セット | 酒 + ホットスナック |

セットはデータ(`.tres`)で持ち、コードを変えずに追加できる。
