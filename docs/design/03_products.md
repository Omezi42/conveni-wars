# 3章 商品とカテゴリ

## 3.1 カテゴリ

おにぎり・弁当・パン・飲料・コーヒー・菓子・ホットスナック・日用品・酒・カップ麺・スイーツ・アイス の12種類。
客層の欲しいもの(2章)と組み合わせボーナス(4章)はカテゴリ単位で決まる。
棚は9マス(4章)なので、すべてのカテゴリは置けない。次に来る客を読んで置くカテゴリを選ばせるため。

**おにぎり・弁当・パン・スイーツ は日持ちしない**カテゴリで、届いてから時間がたつと廃棄される(6.4節)。

## 3.2 商品

商品は「名前・カテゴリ・定価・原価」を持つ。原価は発注するときに払う1個あたりの値段(6章)。
同じカテゴリでも、定価が高く1個の売上が大きい商品と、安くて回転させやすい商品がある。
