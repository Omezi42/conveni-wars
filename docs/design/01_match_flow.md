# 1章 試合の流れ

## 1.1 全体

1. 店長を選ぶ(7章)
2. 試合(300秒)。止まらずに進み、プレイヤーは好きなときに操作する(6章・5章・4章・7章)
3. 結果発表

## 1.2 時間帯

試合は4つの時間帯を順に進む。時間帯ごとに来る客層の割合が変わる(2章)。

| 時間帯 | 長さ | 主な客層 |
|---|---|---|
| 朝 | 75秒 | 会社員・学生・高齢者 |
| 昼 | 75秒 | 会社員(ラッシュ)・主婦・高齢者 |
| 夕方 | 75秒 | 学生・主婦・会社員 |
| 夜 | 75秒 | 若者・夜勤・会社員 |

- 画面には**いまの時間帯と、次の時間帯の客層予報**を常に出す(9章)。先回りして発注させるため
- 試合開始時に10秒の**開店準備**があり、その間は客が来ない。最初の発注と陳列をする時間
  (開店準備は300秒に含めない)

## 1.3 資金

- 開始時の資金は **2,000円**
- 発注すると資金が減り(6章)、商品が売れると売値がその場で資金に加わる
- 資金が足りない発注はできない

## 1.4 勝敗

- 試合終了時の**売上の合計**が多いほうが勝ち(資金の残りは関係ない)
- 同じなら来店した客の数が多いほうが勝ち。それも同じなら引き分け
- 売上だけで競うが、資金の制約があるため、安売りしすぎると次の発注が細って結局売上が伸びない
