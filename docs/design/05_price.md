# 5章 値段

## 5.1 値段の段階

商品ごとに5段階から選ぶ。初期値は「定価」。売値は10円未満を四捨五入する。

| 段階 | 売値 |
|---|---|
| 大安売り | 定価 −20% |
| 安売り | 定価 −10% |
| 定価 | 定価 |
| 強気 | 定価 +10% |
| 超強気 | 定価 +20% |

- 値段は商品単位。同じ商品を複数のマスに置いたら同じ値段になる
- **同じ商品は、値段を変えてから10秒間は変えられない**(連打による値下げ合戦を防ぐため)
- 相手の棚と値段は常に見える

## 5.2 値段補正(魅力度への効き方)

```
値段補正 = 1 − 値段への敏感さ × 変化率 × 2.5
```

変化率は −0.2〜+0.2。例:敏感さ0.9の学生に対して、大安売り(−0.2)は ×1.45、超強気(+0.2)は ×0.55。
敏感さ0.3の会社員なら、それぞれ ×1.15 と ×0.85。
値段に鈍い客層が多い時間帯は強気にしても客が逃げにくい、という読みが生まれる。
