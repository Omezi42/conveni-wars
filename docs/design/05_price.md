# 5章 値段

## 5.1 値段の段階

商品ごとに3段階から選ぶ。初期値は「定価」。売値は10円未満を四捨五入する。

| 段階 | 売値 |
|---|---|
| 安売り | 定価 −20% |
| 定価 | 定価 |
| 強気 | 定価 +20% |

- 3段階にするのは、忙しい中でもタップ1回で迷わず選べるようにするため
- 値段は商品単位。同じ商品を複数のマスに置いたら同じ値段になる
- **同じ商品は、値段を変えてから10秒間は変えられない**(連打による値下げ合戦を防ぐため)
- 相手の棚と値段は常に見える

## 5.2 値段補正(魅力度への効き方)

値段は**相手の店の同じカテゴリの値段と比べて**効く。

```
値段補正 = 1 − 値段への敏感さ × (自店の段階の率 − 比べる率) × 2.5    (0未満にはしない)
```

- 段階の率は 安売り −0.2 / 定価 0 / 強気 +0.2
- 比べる率は、相手が同じカテゴリの商品を棚に置いていて在庫があるとき、そのうちいちばん安い段階の率。置いていなければ 0(定価と比べる)
- 例:相手が定価のとき、敏感さ0.9の学生に対して安売りは ×1.45、強気は ×0.55。相手も安売りなら、こちらの安売りは ×1.0(差が無い)
- 両店で下げ合っても客の取り合いは変わらず利益だけが減る。「下げるか、据え置いて耐えるか」の読み合いを作るため
- 値段に鈍い客層が多い時間帯や、相手が置いていないカテゴリは強気にしても客が逃げにくい、という読みが生まれる
