# コンセプト

向かい合った2軒のコンビニで、**同じ客を取り合う**リアルタイム対戦ゲーム。1試合5分。

- 3×3の棚に商品を並べ、来る客層が欲しがる商品を揃えた店に客が入る
- 時間帯ごとに客層が入れ替わる。**次に来る客を読んで先に仕入れる**のが中心の判断
- 値段を上げ下げして相手を出し抜く。ただし安売りしすぎると仕入れる資金が尽きる
- 商品の置き方・組み合わせでボーナスが付く
- 店長キャラを選ぶ。パッシブスキルは常に効き、アクティブスキルは試合中に1回だけ使える

売上の多いほうが勝ち。

## 開発方針

- 最初はCPU戦で作り、ゲームの核と面白さを固める。オンライン対人戦は後で足す(99章)
- Web(ブラウザ)で配布する。マウスとタッチの両方で遊べるようにする
