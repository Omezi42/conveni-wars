# コンセプト

向かい合った2軒のコンビニで、**同じ客を取り合う**リアルタイム対戦ゲーム。1試合5分。

- 3×3の棚に商品を並べ、来る客層が欲しがる商品を揃えた店に客が入る
- 時間帯ごとに客層が入れ替わり、突発イベントの客が押し寄せる。**次に来る客を読んで先に仕入れる**のが中心の判断
- 値段を上げ下げして相手を出し抜く。ただし安売りしすぎると仕入れる資金が尽きる
- 仕入れすぎると廃棄が出て、少なすぎると客を逃す
- 商品の置き方・組み合わせでボーナスが付く
- 店長キャラを選ぶ。パッシブスキルは常に効き、アクティブスキルは試合中に1回だけ使える

利益(売上 − 仕入れ)の多いほうが勝ち。

## 手触りの方針

- **常に忙しい。ただし忙しさは手の速さではなく、次々に来る判断で作る。**読みの正確さで勝ち負けが決まり、頭のいい人が勝つ
- 待ち時間を作らない。操作や読みが当たるたびに、すぐに気持ちいい反応を返す(9章)
- ルールは一目で分かるようにする。数字より色・アイコン・点滅で状態を伝える
- **初めて開いた人が、最初のクリックから数秒で「自分の棚に客が流れ込んで売れる」を味わう。**説明は止めて読ませず、起きたことにその場で答える形で出す(9.7節)。読む前に遊ばせ、遊びながら分からせるため

## 開発方針

- 最初はCPU戦で作り、ゲームの核と面白さを固める。オンライン対人戦は後で足す(99章)
- Web(ブラウザ)で配布する。マウスとタッチの両方で遊べるようにする
