# 9章 画面構成とUI

画面は横長 1280×720 を基準にする。ボタン・パネル・枠はコードで描き、イラストは商品・店長・客・背景だけに使う。
状態は数字より色・アイコン・点滅で伝える(コンセプトの手触りの方針)。

## 9.1 画面の流れ

タイトル → 店長選択 → 試合 → 結果 → (もう一度 / タイトルへ)

## 9.2 試合画面

```
┌ わたしの店 ¥売上 ─┬── 時間帯 時計 残り ──┬─ 相手の店 ¥売上 ┐
│ 商品タイル 3列     │ 客層予報(いま/次)     │ 相手の棚(小)       │
│ (在庫・廃棄・入荷 │ 背景:向かい合う2軒と  │                    │
│  ・発注ボタン)     │ 流れ込む客・イベント  │ 来店数・取り逃し   │
│                    ├─────────┬────┤ (両店ぶん)         │
│ 資金               │ 自分の棚 3×3  │ 値付け   │                    │
│ 店長の顔+スキル    │ (大)         │ ボーナス │                    │
└──────────┴─────────┴────┴──────────┘
```

| 場所 | 表示するもの |
|---|---|
| 上端 | 左に自店、右に相手の店の名前と売上。中央に時間帯・店の時計・残り時間 |
| 左 | 商品タイル(3列)。1枚に商品・在庫数・廃棄までの残り秒数・入荷までの残り秒数・発注ボタン(1ロットの代金) |
| 左下 | 資金・店長の顔・アクティブスキルのボタン |
| 中央上 | 客層予報(いまの時間帯と次の時間帯を横に並べる。客層アイコンの大きさで量を見せる) |
| 中央 | 背景の2軒の店(左が自店・右が相手)と、その入口へ流れ込む客。突発イベントの予告はここに帯で出す(11章) |
| 中央下 | 自分の棚(大きく表示。操作する)と、その右に値付けパネル・ボーナスのパネル |
| 右 | 相手の棚(小さく表示。商品・在庫・値段が見える)と、客層ごとの来店数(両店ぶん)・この時間帯に取り逃した客の数(2.6節) |

- 発注は商品タイルの発注ボタンを押す(タブで分けない。発注は数秒に1回あり、切り替えの手間が重いため)
- 客は1人ずつ歩かせず、**両店の入口へ流れ込む人の流れ**として描く。流れの中に客層のアイコンを混ぜ、
  どの客層がどちらの店へ多く入っているかが見えるようにする(1秒に4〜9人来るため)
- 取り逃した客は、流れから外れて「〇〇が無い…」の吹き出しを出す。吹き出しは画面が埋まらないよう間引いて出す(数は全員数える)
- 棚のマスには商品・在庫数・売値を表示し、成立しているボーナス(目玉・コーナー・セット)を枠の色と名前で示す。
  在庫が残り少ない商品は点滅し、在庫が切れたマスは赤くする
- 棚のマスか商品タイルをタップすると、その商品を**値付けパネル**に出す。値段の3段階はパネルのボタンをタップ1回で選ぶ。
  値段を変えられない間は鍵の印と残り秒数を出す。棚のマスから選んだときは「棚から外す」も出す
- ボーナスのパネルは目玉・コーナー・セットの3種類を常に出し、成立しているものを光らせて名前を出す(ルールを画面で覚えられるように)

## 9.3 演出

操作や読みが当たるたびに、すぐに気持ちいい反応を返す。

- 商品が売れるたびに、そのマスから「+¥160」が飛び出し、売上の数字がチャリンと回る
- 時間帯が変わるときに「昼ラッシュ!」などのカットインを出す
- 突発イベントの客を多く取れたら「大口獲得!」の大きな演出を出す(11章)
- 客数で相手を逆転した瞬間に表示を出す
- 残り30秒でBGMを速くする

## 9.4 結果画面

- 大きく「WIN! / LOSE… / DRAW」を出し、両店のカードを「VS」を挟んで並べる。カードには店長の顔を入れる
- カードには売上・来店した客の数・取り逃した客の数・廃棄した個数と、客層ごとの来店数を出す
- カードの下に「主な差分」(売上・来店した客・取り逃した客・廃棄の、自店−相手)の帯を出す。良い向きの差は緑、悪い向きは赤
- ボタンは「もう一度」(黄)と「タイトルへ」

## 9.5 店長選択画面

- 店長ごとのカードを横に並べる。カードの上半分に店長の顔、店長の色の帯に名前
- 「パッシブ」「アクティブ」は色付きのラベルにし、その後ろに効果を書く。アクティブはスキル名を太く出す
- 選んだカードは黄色の縁で光らせる。「決定」ボタン(黄)で開店する

## 9.6 見た目の方針

- 背景は通りを挟んで並ぶ2軒のコンビニの絵(左が自店=青、右が相手=赤)。全画面で共通に使う
- パネルは濃い紺の半透明に明るい縁取り、角を丸くする。棚のマスと商品タイルは明るい地にする(商品の絵を読みやすく)
- 自店は青、相手は赤で統一する。主な操作のボタン(はじめる・決定・もう一度)は黄色
- 商品・客層・店長・時間帯の絵は無料素材(Twemoji、CC-BY 4.0)を使い、タイトル画面に出典を出す。背景はSVGで描く
