# 9章 画面構成とUI

画面は横長 1280×720 を基準にする。ボタン・パネル・枠はコードで描き、イラストは商品・店長・客・背景だけに使う。
商品・客層・店長の絵はこのゲーム用に生成AIで作る(9.6節)。
状態は数字より色・アイコン・点滅で伝える(コンセプトの手触りの方針)。

## 9.1 画面の流れ

タイトル → 店長選択 → 試合 → 結果 → (もう一度 / 店長を選ぶ / タイトルへ)

試合は一時停止して、やり直す・タイトルへ戻ることもできる(9.9節)。

- タイトルには「はじめる」「遊び方」「設定」を置く。遊び方はヒント(9.7節)を最初から出し直して試合を始める
- **戦績が1試合も無いときの「はじめる」は、店長選択を飛ばしてそのまま試合を始める。**店長はベテラン、CPUはやさしい(8.3節)。
  最初のクリックから数秒で遊ばせるため。ベテランは効果が分かりやすく、値段の読み合いを知らなくても使えるため
- 店長選択の画面でCPUの強さ(8.3節)も選ぶ。3つのボタンの上に「CPUの強さ」の見出しを1つ置く
- 結果画面の「もう一度」は同じ店長ですぐ次の試合、「店長を選ぶ」は店長選択へ進む

## 9.2 試合画面

初めて遊ぶ人がすぐ読めるよう、枠の数を絞り、同じ種類の情報は1か所にまとめる。

| 場所 | 表示するもの |
|---|---|
| 上端 | 左=いまの時間帯・天気(12章)・1日の進み・残り時間(1つの枠)、中央=両店の利益と綱引きのバー・その真下の中央に、いまの時間帯に自店へ入った客の割合の小さな札、右端=一時停止のボタン(9.9節) |
| 中央左 | 自店の店と棚(大きく表示。操作する)。棚のマスで、その商品の在庫・廃棄までの残り・入荷待ちを見て発注もできる。看板にボーナスの見方を出す「?」と、この時間帯に取り逃した客の数の赤い札(0人なら出さない。2.6節) |
| 中央 | 2軒のあいだの通りと、両店へ流れ込む人の流れ |
| 右上 | 相手の店と棚(小さく表示。商品の絵と値札だけ。在庫が切れたマスは赤くする) |
| 右下 | 次の時間帯の予報(欲しがられるカテゴリを商品の絵とカテゴリ名で大きい順に並べる。自店の棚に在庫ありで並んでいるカテゴリには緑のチェックを付け、予報と棚がつながって見えるようにする)。突発イベントの予告が出ている間は、この枠を予告に切り替える(11章) |
| 下端 | 品ぞろえ(棚に出ていない商品だけをカテゴリ順に並べた札。在庫数・廃棄までの残り・入荷待ち・1ロットの代金を書いた発注ボタンを出す)・資金・アクティブスキルのボタン |

- 文字を読める大きさに保つため、1か所に出す情報を絞る。時刻は時計を出さず、空の色と1日の進みのバーで伝える。客数・客層の内訳は出さない(勝敗は利益で決まるため)
- ただし、いまの時間帯に自店へ入った客の割合だけは、綱引きのバーの下に小さな札で出す(例「客 62%」)。読みの当たり外れを、時間帯が終わる前に直せるようにするため
  - 割合は時間帯のカットインの成績(9.3節)と同じ数え方にする(突発イベントの客を除き、両店に入った客のうちの自店の割合)
  - 色は「読み的中!」の基準(9.3節)に合わせる。基準以上=緑の地、外れの基準以下=赤の地、そのあいだ=白の地に紺の字
  - 時間帯が始まってから両店に入った客が10人に満たないあいだは出さない(始まった直後に0%と100%で色が点滅しないようにするため)
- 品ぞろえに棚の商品を出さないのは、札の数を半分にして1枚を大きくするため
- 予報に「いま」の時間帯は出さない。いまの時間帯は上端と空の色で分かるため
- ボーナスの見方は、看板の「?」にカーソルを乗せるか押すと棚の上に重ねて出す(もう一度押すと消える)
- 売っている商品の発注は棚のマスで行い、品ぞろえは棚へ出す商品を選ぶ所にする。1つの商品の操作を1か所にまとめ、目を棚から離さずに発注できるようにするため
- 「+¥」の飛び出しは自店の棚からだけ出す。相手の稼ぎは上端のバーで分かり、画面が埋まらないようにするため
- 客は全員を1人ずつ歩かせず、**両店の入口へ流れ込む人の流れ**として描く。流れの中に客層のアイコンを混ぜ、
  どの客層がどちらの店へ多く入っているかが見えるようにする(1秒に4〜9人来るため)
- 流れとは別に、**1秒に1人ほどを「見える客」として大きく描く。**客層の絵で通りを歩き、頭の上の吹き出しに欲しい物の絵を出して、
  選んだ店の入口へ入る。自店に入った客は、買った商品のマスを光らせて「+¥」を出す。
  「欲しい物を並べた店に客が入る」を、説明なしで目に見せるため
  - 吹き出しの絵は、入った店で最初に買った商品。取り逃した客(2.6節)は、いちばん欲しがったカテゴリの絵に×を付け、
    「〇〇が無い…」と出したまま相手の店へ(両店とも0なら通りの外へ)歩いていく
  - 取り逃した客は、見える客の間引きとは別に、自店が取り逃した客を優先して見える客にする(直す手がかりなので見逃させない)
  - カテゴリの絵は、そのカテゴリの商品のうち並び順が最初の商品の絵を使う
- 棚のマスには商品の絵・在庫数・廃棄までの残りのバー・入荷待ち(「+30」の札。残り時間は札の塗りで示す)・売値・発注ボタン(1ロットの代金)を表示し、商品名は出さない。成立しているボーナス(目玉・コーナー・セット)を枠の色と名前で示す。
  在庫が残り少ない商品は点滅し、在庫が切れたマスは赤くする
- マスの発注ボタン以外をタップすると値段の3段階のボタンが出て、タップ1回で選べる。値段を変えられない間は残り秒数を出す
- 同じメニューの「棚から外す」の横に、自動発注(6.5節)の切り替えボタンを置く。オンのときは沈んで緑のチェックを付ける。
  長押しにしないのは、タッチの長押しはWebで扱いにくく見つけにくいため
- 自動発注がオンの商品のマスは、発注ボタンの上の段の文字を「発注」から「自動」に変え、ボタンの枠を緑にする(ひと目でどのマスがオンか分かるようにするため)

## 9.3 演出

操作や読みが当たるたびに、すぐに気持ちいい反応を返す。

- 自店の商品が売れるたびに、そのマスから「+¥160」(売値)が飛び出し、利益の数字がチャリンと回る
- 時間帯が変わるときに「昼ラッシュ!」などのカットインを出し、その下に**終わった時間帯の成績**を1行添える
  - 自店に入った客の割合を出す(例「朝の客 62%」)
  - 55%以上なら「読み的中!」を大きく出す。45%以下で、その時間帯に負けた理由(2.7節)が1件以上あれば、
    人数がいちばん多い理由(同数なら 品切れ → 品ぞろえ → 値段 → ボーナス の順)で次の1行を添える。
    読みが結果につながったことと、次に直す手を時間帯ごとに返すため
    - 品切れ:「次は〇〇を並べよう」
    - 品ぞろえ:自店の棚にそのカテゴリが在庫ありで無ければ「次は〇〇を並べよう」、あれば「次は〇〇を増やそう」。
      カテゴリが無ければ「次は品ぞろえを増やそう」
    - 値段:「次は〇〇の値段を見直そう」
    - ボーナス:「次は棚のボーナスを組もう」
- 突発イベントの客を多く取れたら「大口獲得!」の大きな演出を出す(11章)
- 利益で相手を逆転した瞬間に表示を出す
- 残り30秒でBGMを速くする

## 9.4 結果画面

両店の利益・売上・仕入れ・来店した客の数・取られた客の数(負けた理由が付いた客の合計。2.7節)・廃棄した個数を並べ、利益で勝ち負けを出す。
選んだ店長の自己ベストの利益を更新したら「自己ベスト更新!」を出す(9.7節)。
勝って、その店長でそのCPUの強さに初めて勝ったら「★ つよいに初勝利!」のように勝ち星(9.7節)が増えたことを出す。

**ふりかえり**:2枚のレシートのあいだに、両店の利益が試合の中でどう動いたかの折れ線(自店=青、相手=赤)を出す。見出しに天気(12章)を添える。
どこで差が付いたかを見て、次の試合の読みを直す手がかりにするため。

- 横軸は試合の時間。時間帯の境目に縦の線を引き、各時間帯の下に名前と、その時間帯に自店へ入った客の割合を出す。
  割合が「読み的中!」(9.3節)の基準以上なら緑、以下の基準以下なら赤にする
- 割合の下に、その時間帯でいちばん多い負けた理由(2.7節。同数の順は9.3節)を「品切れ」「品ぞろえ」「値段」「ボーナス」で短く出す。
  どの時間帯で何に負けたかを一目で分かるようにするため
- 突発イベントが起きた時刻に黄色の印を付ける。自店が大口獲得(11.2節)したイベントは★にする
- 利益は1秒ごとに記録する

**CPUならどうしたか**:折れ線の下に、CPUの手と比べて自店が最も損をした時間帯を1〜2個、言葉で出す。
どこで差が付いたかだけでなく、次の試合で何を直せばよいかを具体的に示すため。

- 同じ乱数の種で、1つの時間帯の間だけプレイヤーの発注・棚・値段を相手と同じ強さのCPUの判断に任せて計算し直す。
  ほかの時間帯とアクティブスキルは、プレイヤーが実際にした手のまま
- 比べるのは、時間帯の終わりの「利益 + 手元の在庫と発注中の商品の仕入れ値」の「自店 − 相手」の差。
  在庫を含めるのは、次の時間帯に備えて先に仕入れた分を損として数えないため
- この差が3,000円以上よくなった時間帯を、よくなった額の大きい順に最大2つ出す。
  例:`昼:のり弁当とお茶を並べていれば 差 +¥18,400(取り逃し 85人→20人)`
  - 商品名は、その時間帯に在庫ありで棚に並んでいた時間がプレイヤーよりCPUのほうが15秒以上長かった商品(長かった順に最大2つ)
  - そういう商品が無ければ `発注と値付けを変えていれば` と書く
- どの時間帯も基準に届かなければ `どの時間帯もCPUの手と互角以上!` と出す
- 計算は結果画面を開いてから何フレームかに分けて進め、画面を止めない。終わるまでは `計算中…` を出す。
  Webで5秒以内に終えることを目標にし、超えるときは自店の客の割合が「読み的中!」の基準に届かなかった時間帯だけを計算し直す

**結果の共有**:結果画面をそのまま1枚の画像にして、保存したりSNSへ共有したりできるようにする。遊んだ結果が人の目に触れ、新しい遊び手を呼ぶため。

- 画像に載せるもの:ボタンを除いた結果画面全体(勝敗の文字・両店のレシート・「勝」の判・ふりかえり・CPUならどうしたか・自己ベストや初勝利の札)。
  ボタンがあった下の帯には「コンビニウォーズ」の題字とCPUの強さ(例:「CPU つよい」)を入れる
- 大きさは1280×720(16:9)。SNSのタイムラインで切れずに出る比率にするため。ウィンドウの大きさや黒帯に関係なくこの大きさにそろえる
- ボタンは下の段の右端、「タイトルへ」の右に4つ目として置く

| 環境 | ボタンの言葉 | 押したとき |
|---|---|---|
| Web(指で操作する端末) | 結果を共有 | 端末の共有シート(Web Share API)を開き、画像と文と遊んでいるページのURLを渡す |
| Web(PC、または共有シートが使えないブラウザ) | 結果を共有 | 画像を `conveni-wars_年月日_時分秒.png` としてダウンロードする |
| デスクトップ | 画像を保存 | 「ピクチャ/コンビニウォーズ」へ同じ名前で保存する |

- PCのブラウザは共有シートが使えてもダウンロードにする(Windowsの共有画面はSNSへつながりにくく、画像を手元に残す方が投稿しやすいため)。
  指で操作する端末かは `pointer: coarse` で見分ける
- 共有する文:「コンビニウォーズでCPU(つよい)に勝ち! 利益 ¥12,345 #コンビニウォーズ」。負けは「〜に負け…」、引き分けは「〜と引き分け」
- 保存・ダウンロードしたら、ボタンの上に「画像を保存しました」を2秒出す。共有シートを閉じた(キャンセルした)ときは何も出さない
- 「CPUならどうしたか」の計算が終わるまではボタンを押せなくする(画像に「計算中…」を写さないため)

## 9.5 見た目

舞台は「時間帯で空の色が変わる街で、看板を掲げた2軒のコンビニが通りを挟んで向かい合う」。
太い紺の輪郭線と、下へずらしたくっきりした影の「ステッカー」風で統一する(どんな空の色の上でも部品が埋もれないため)。

- **空**:背景は時間帯ごとの空の色(朝=水色・昼=青・夕方=茜色・夜=紺と星)。時間帯が変わると数秒かけて移る。
  空の色で1日のいまが分かるようにするため。色は時間帯のデータに持つ
- **店**:店の色の看板と帯(自店=青、相手=赤)・明るい床・通りに面したガラスの入口。相手の店は通りの向こうとして小さく描く
- **通り**:2軒のあいだを上から見た道(歩道・車道・中央の破線)。夜は暗くなり、入口の前に店の明かりがこぼれる
- **棚**:各段の手前に棚板があり、値札は棚板に掛かる。在庫数はアイコンの右上の札で出す。成立したボーナスはマスの色枠と、マスの左上に縦に並べた名前の札(目玉・コーナー・セット)で示す。相手の棚は色枠だけ
- **値札の色**:安売り=黄色の特価札に赤い文字、定価=白、強気=紺に黄色い文字。値段のボタンも同じ色にする
- **ボタン**:押している間は影の位置まで沈む。選ばれているものは沈んだまま緑のチェックを付ける
- **文字**:1280×720 基準で最小16px。収まらないときは文字を小さくせず、出す情報を減らす。空や色の付いた地の上の数字・見出しは太く縁取りする。フォントは Zen Kaku Gothic New Bold の1つだけ
- **お金**:売上の飛び出し・資金の硬貨・「はじめる」などの主役のボタンは黄色
- **予報**:空の小窓・時間帯の名前・始まるまでの秒数の下に、欲しがられるカテゴリを商品の絵で大きい順に並べる。突発イベントの予告は黄色と紺の縞の枠で点滅させる
- **画面ごと**:タイトル=夕暮れの通りに向かい合う2軒の店と題字・1行の惹句。文字のルール説明は置かない(遊びながら分からせるため)。
  背景では裏でCPUどうしの試合を回し、見える客(9.2節)が欲しい物の吹き出しを出して2軒の店へ入っていく様子を動かす(音は鳴らさない)。
  押す前から何をするゲームかが見えるようにするため。店長選択=社員証の形のカード。店長の色の地の右下に勝ち星(9.7節)を3つ並べ、勝った強さの星だけ黄色く塗る。
  結果=閉店後の夜空の下に両店の成績をレシートの形で並べ、勝った店に赤い「勝」の判を押す
- アクティブスキルの説明はボタンにカーソルを乗せると出す(ボタンには名前と状態を大きく出す)

## 9.6 絵の決まりと一覧

絵は画面で30〜70pxの大きさで出るため、細部より**形と色で一目で分かる**ことを優先する。
既製の絵文字や素材のような「どこかで見た絵」に見えないよう、全部を1つの画風で揃える。

**画風(全部に共通)**

- UIと同じステッカー風:太くて均一な濃い紺(#1d2342)の輪郭線、ベタ塗り+影1段、光沢やグラデーションは使わない
- 背景は白以外で、絵に使わない無地1色(ふつうは明るい緑、緑の絵はピンク)。影・地面・文字・ロゴは描かない(影はゲームが描く)
- 1枚に1つ、中央に大きく(余白は少し)。商品は少し上から見た斜め、人物は正面の胸から上
- 画風を揃えるため、1枚の画像に4〜9個を並べて生成してよい(切り分けは取り込み側で行う)

## 9.7 ヒント・戦績・設定

**ヒント**
- 試合を止めて読ませる案内は出さない。代わりに、**初めてその出来事が起きたとき、その場所を指す1行の吹き出し**を出す
- ヒントごとに端末で1回だけ出す。タイトルの「遊び方」から始めたときは、全部を出し直す
- 吹き出しは試合も操作も止めない。指した操作をしたとき、または6秒たったら消える。同時に出すのは1つだけで、重なったものは前のものが消えてから出す

| きっかけ | 指す所 | 言葉 |
|---|---|---|
| 試合が始まって3秒 | 予報 | 次に来る客が欲しがる物。先に発注して並べよう |
| 自店が初めて客を取り逃した | 品ぞろえのそのカテゴリの札 | 〇〇を探して相手の店へ! 棚へドラッグで並べよう |
| 自店の棚の商品が初めて在庫が少なくなった | そのマスの発注ボタン | 押すと5秒で30個届く |
| 初めて突発イベントの予告が出た | 予告の枠 | 20人がまとめ買いに来る。先に並べよう |
| 同じ商品を手で3回発注した | そのマスの値札 | タップして自動発注にできる |
| 相手が初めて、自店の棚と同じカテゴリを自店より安くした | 自店のそのマスの値札 | 値札をタップして値段を変えられる |
| 残り150秒 | アクティブスキルのボタン | スキルは1試合に1回。ここぞで使おう |

- 「〇〇」はカテゴリの名前。品ぞろえのそのカテゴリの札は、品ぞろえに出ている(棚に無い)商品のうち並び順が最初の札。無ければこのヒントは出さない

**戦績**(端末に保存する)
- 勝ち・負け・引き分けの数
- 出したヒント(9.7節)
- 店長ごとの自己ベストの利益
- 店長ごとの勝ち星:CPUの強さ(やさしい・ふつう・つよい)ごとに、その店長で勝ったことがあるか。
  全店長で星3つを揃えることを、長く遊ぶ目標にするため。引き分けは数えない
- 最後に選んだCPUの強さ

**設定**(タイトルの「設定」。端末に保存する)
- BGMの音量・効果音の音量(それぞれ 0〜100%)
- 全画面の切り替え(ブラウザでも使える)

## 9.8 音

素材はフリー素材(商用可・改変可のもの)を使い、出典は `assets/audio/CREDITS.md` に書く。

| 鳴らすとき | 音 |
|---|---|
| 試合中 | BGM(ループ)。残り30秒で速くする(9.3節) |
| タイトル・店長選択・結果 | 試合とは別の落ち着いたBGM |
| 自店の商品が売れた | 硬貨の「チャリン」。0.1秒に1回までに間引き、続けて売れるほど少しずつ音程を上げる(1秒あくと戻す) |
| 発注した | 軽い決定音 |
| 発注が届いた(自店) | 小さな「ポン」 |
| 自店の棚の商品が在庫切れになった | 低い短い音 |
| 時間帯のカットイン・イベントの予告 | 短いジングル / 注意の音 |
| 大口獲得・逆転 | 明るいジングル |
| 勝ち / 負け | 勝ちのジングル / 負けのジングル |
| ボタンを押した | 短いクリック音 |

- 同じ音は0.1秒に1回までに間引く(1秒に最大9人来るため)
- Webでは最初のクリックまで音が鳴らない。タイトルで最初に押した時点から鳴らす

## 9.9 一時停止

試合画面の上端の右端に一時停止のボタン(縦の2本線)を置く。Escキーでも開く(品ぞろえの札を選んでいるときのEscは選択の解除を先にする)。
ブラウザのタブや窓から離れたときも自動で一時停止する。

- 止めている間は、試合の時間・客・発注の到着・CPUがすべて止まる
- 画面全体を暗い幕で覆い、中央に「続ける」「やり直す」「タイトルへ」を出す。幕で棚・予報・相手の店は見えなくする
  (止めたまま考える使い方を防ぎ、限られた時間の中で読む遊びを保つため)
- 「やり直す」は同じ店長・同じCPUの強さで、新しい試合を始める。「やり直す」「タイトルへ」でやめた試合は戦績に数えない
- 閉店(試合の終わり)のあとは開けない
- 対人戦(99章)では使えなくする
