# 9章 画面構成とUI

画面は横長 1280×720 を基準にする。ボタン・パネル・枠はコードで描き、イラストは商品・店長・客・背景だけに使う。

## 9.1 画面の流れ

タイトル → 店長選択 → 試合 → 結果 → (もう一度 / タイトルへ)

## 9.2 試合画面

| 場所 | 表示するもの |
|---|---|
| 上端 | 残り時間・いまの時間帯・両店の売上 |
| 右上 | 次の時間帯の客層予報(客層アイコンと割合) |
| 中央左 | 自店の棚(大きく表示。操作する) |
| 中央右 | 相手の棚(小さく表示。商品・在庫・値段が見える) |
| 左端 | 発注パネル(商品の一覧と原価。タップで1ロット発注) |
| 下端 | 倉庫(届いた商品と個数、発注中の商品と残り秒数)・資金・アクティブスキルのボタン |

- 客は画面下から歩いてきて、選んだ店へ入る。どの客層がどちらの店へ行ったかが見えるようにする
- 棚のマスには商品・在庫数・売値を表示し、成立しているボーナス(目玉・コーナー・セット)を枠の色と名前で示す
- マスをタップすると値段の5段階を選ぶメニューが出る。値段を変えられない間は残り秒数を出す

## 9.3 結果画面

両店の売上・来店した客の数・客層ごとの来店数を並べ、勝ち負けを出す。
