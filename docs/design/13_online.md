# 13章 オンライン対戦

離れた2人が、合言葉で同じ部屋に入るか、ランダムマッチで組んで対戦する。ルール・数値・試合画面はCPU戦と同じで、相手がCPUから人に替わるだけにする。

## 13.1 方式

- 両方の端末で同じ試合の計算を回し、送り合うのは自分の操作(発注・配置・値段・自動発注・アクティブスキル)だけにする。
  試合は種と操作の列が同じなら同じ結果になるため(10章)。客の動きを送らずに済み、通信量が小さい
- 操作は押した時点から約0.17秒後の決まった tick で、両方の端末で同時に実行する。押した直後の手応え(発注ボタンの光りなど)はその場で返す
- 相手の操作がまだ届いていない tick へは進まない。1秒以上待つあいだは「相手を待っています…」と出す
- 時間帯が変わるたびに、両方の試合の状態が一致しているかを照らし合わせる。食い違ったら試合を打ち切り「通信のずれで試合を中止しました」と出す(戦績に数えない)
- 対戦はWeb版どうしで行う(小数の計算が端末の種類で変わらないようにするため)
- 2人をつなぐのは中継サーバー(部屋ごとに文を相手へ流すだけ)。試合の判定はサーバーでは行わない

## 13.2 部屋とマッチング

タイトルの「オンライン対戦」から部屋の画面へ進む。

- 「部屋を作る」:4桁の合言葉を出し、相手が入るのを待つ。合言葉は相手へ別の手段(SNS・チャットなど)で伝える
- 「合言葉で入る」:画面の数字のボタン(0〜9・1字消す)で4桁を入れる。キーボードの数字でも入れられる。
  タッチの端末で文字入力の欄を出さずに済むようにするため
- 部屋が無い・満員・つながらないときは理由を1行で出し、入れ直せるようにする
- 「ランダムマッチ」:同じくランダムマッチで待っている人と組む。待っている人がいなければ「相手を探しています…」と出して、来るまで待つ(「やめる」で戻れる)。
  合言葉を伝える相手がいない人も遊べるようにするため。遊ぶ人が少ないうちは待っても来ないことがあるので、合言葉の部屋を主にする
- 2人がそろったら店長選択へ進む。CPUの強さのボタンは出さない。両方が選んだら試合を始める(同じ店長どうしも可)。
  先に選んだ側は、開店のボタンの文字を「相手を待っています…」に替えて押せなくする(ボタンの裏に文字を重ねないため)
- 種と天気は部屋を作った側(ランダムマッチは先に待っていた側)が決める。その側が試合の店0、もう一方が店1になるが、どちらの画面でも自分の店を左(自店の色)に出す

## 13.3 試合中

- 一時停止は使えない(9.9節)。上端の右端のボタンは「降参」のメニューを開き、「降参する」「続ける」を出す。開いている間も試合は進む
- 降参した側は負けとして戦績に数え、タイトルへ戻る
- ヒント(9.7節)は出さない
- 相手が降参した、または相手の通信が10秒途切れたら、「相手の通信が切れました。相手の店はCPUが続けます」と出し、
  相手の店をCPU(ふつう)に任せて試合を最後まで進める。結果は利益にかかわらず自分の勝ちにする
- 自分の側が10秒以上止まっていた(タブを離れていた)ことを相手が知らせてきたら、「通信が切れました」と出してタイトルへ戻る(戦績に数えない)

## 13.4 結果と戦績

- 結果画面はCPU戦と同じ。ただし「CPUならどうしたか」(9.4節)は出さない(相手が人なので、計算し直すには相手の操作も記録する別の作りが要るため)
- 結果画面のボタンは「タイトルへ」と結果の共有だけにする。もう一度遊ぶときは部屋を作り直す
- オンラインの勝ち・負け・引き分けはCPU戦とは分けて数え、部屋の画面に出す。CPU戦の戦績・自己ベスト・勝ち星には数えない
