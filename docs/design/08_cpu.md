# 8章 CPU戦

相手はCPU。CPUもプレイヤーと同じ操作(発注・陳列・値付け・アクティブスキル)だけを使い、ルール上の特権を持たない。

## 8.1 CPUの店長

プレイヤーが選ばなかった店長からランダムに1人選ぶ。

## 8.2 CPUの動き(最初の版)

3秒ごとに次を順に判断する。

1. **発注**:いまと次の時間帯の客層から、欲しがられる度合いが高いカテゴリを選び、
   棚と倉庫と発注中の合計が少ない商品を資金の許す範囲で発注する
2. **陳列**:倉庫にある商品を、空のマス → 在庫の少ないマスの順に置く。ボーナスは考えない
3. **値付け**:相手と同じ商品を相手より高く売っていたら、1段階下げる。
   自店だけが置いている商品は定価に戻す
4. **アクティブスキル**:試合の後半(残り150秒以下)に入ったら、その後のランダムな時刻に使う

強さの段階(ボーナスを考えて並べる、客層予報を先読みする など)は、最初の版で遊んでから決める(99章)。
