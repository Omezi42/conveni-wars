# 6章 発注と在庫

プレイヤーの仕事は**発注・棚の配置・値付け(5章)**の3つ。品出しの手間は無くしてある
(1店で1試合に約2,200個売れるため、手で補充させると読み合いより作業になる)。

## 6.1 発注

- 発注パネルから商品を選ぶと、**50個(1ロット)**を発注する。代金は 原価 × 50 をその場で払う
- 発注した商品は**10秒後**(店の時計で約2時間後)に届き、その商品の在庫に加わる。届くまでの残り時間を表示する
- 発注の数と回数に制限はない(資金だけが制約)。1試合の発注は40〜50回ほどになる

## 6.2 在庫

- 在庫は商品ごとに店で1つの数として持つ。上限はない
- **棚に割り当てた商品だけが売れる。**割り当てていない商品は、在庫があっても売れず、魅力度にも数えない(倉庫にある扱い)

## 6.3 棚の配置

- 在庫一覧の商品を棚のマスへドラッグ(またはタップで選んでマスをタップ)すると、そのマスにその商品を割り当てる
- 別の商品が割り当ててあるマスへ置くと入れ替える
- マスの割り当てを外すこともできる
- 在庫がまだ届いていない商品も割り当てられる(届いた時点で売れ始める)
- 配置はすぐに反映され、時間はかからない
