# 6章 発注と倉庫

## 6.1 発注

- 発注パネルから商品を選ぶと、**5個(1ロット)**を発注する。代金は 原価 × 5 をその場で払う
- 発注した商品は**10秒後**に倉庫へ届く。届くまでの残り時間を表示する
- 発注の数と回数に制限はない(資金だけが制約)

## 6.2 倉庫

- 届いた商品は商品ごとに個数がまとまって倉庫に並ぶ。倉庫の容量に上限はない
- 倉庫の商品は魅力度に数えず、売れない。棚へ出して初めて売れる

## 6.3 陳列

- 倉庫の商品を棚のマスへドラッグ(またはタップで選んでマスをタップ)すると、マスの空きぶん(最大10個)を倉庫から移す
- 同じ商品のマスへ置くと在庫を足す
- 別の商品が置いてあるマスへ置くと入れ替える。元の商品の在庫は倉庫へ戻る
- 棚のマスから倉庫へ戻すこともできる
- 陳列はすぐに反映され、時間はかからない
